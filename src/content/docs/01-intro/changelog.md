## 最新版本 v3.2.0 (2026-08-18)

本次更新全面重构了模型基准矩阵与底层审计引擎，锁定 **2026 纯血前沿旗舰体系**，并上线了多项核心功能：

### 1. 新增 2026 前沿旗舰模型原生支持
* **OpenAI GPT-5.6 系列**：原生支持 `gpt-5.6-sol`（旗舰推理与代码）、`gpt-5.6-terra`（全能工作马）、`gpt-5.6-luna`（极速高吞吐）；
* **Anthropic Claude 5 系列**：支持 `claude-fable-5`（终极叙事与高难算法）、`claude-opus-5`（复杂科研与工程）、`claude-sonnet-5`（自适应思考主力军）；
* **Google Gemini 3 系列**：支持 `gemini-3.7-flash`（GA 极速原生思考）与 `gemini-3.1-pro-preview`（超长窗口旗舰）；
* **xAI Grok 4.6 系列**：支持 `grok-4.6`（全模态实时推理与工具生态消费）；
* **彻底清退过时旧代模型**：基准标尺与模型选择器彻底清除历史旧型号，确保全网质检标尺处于业界最新前沿。

---

### 2. 核心鉴别引擎关键升级
* **P1 双回合工具闭环回传检验 (Dual-Turn Tool Roundtrip)**：向模型注入带复杂 Schema 的函数调用，并在次轮以 `role: "tool"` 携带 `tool_call_id` 回传，精确区分是网关中间件丢包还是模型能力缺陷；
* **P2 Python 隔离沙箱单元测试**：针对代码修复题目，将模型生成的代码置入隔离沙箱，直接运行 4 组以上隐藏边界断言，杜绝劣质模型冒充；
* **原生推理思考流结构化捕获**：全面透传并解析 Gemini 3 `thoughts_token_count` 思考 Token 与 Claude 5 Thinking Signature 加密防伪签名；
* **105K+ 超长上下文大海捞针**：在 10 万 Token 级技术文档中随机埋藏动态 Hash 密标，精准测量端到端检索耗时与长文本保真度。

---

### 3. Web 交互体验与批量检测增强
* **批量 Key 智能防封策略**：提供安全防封 (2线程/250ms)、标准平衡 (5线程/50ms)、极速清洗 (10线程/0ms) 及自定义线程控制，内置 ±25% 随机延时抖动 (Jitter Delay) 规避 WAF 封禁；
* **账户余额与可用模型自动穿透嗅探**：批量检测时自动探测账户剩余额度与 `/v1/models` 清单；
* **官方高清矢量 SVG 厂商图标**：全站表格与模型下拉菜单左侧加装 OpenAI、Anthropic、Google、xAI 官方高清矢量图标；
* **丝滑向下展开动画与防模糊渲染**：全站下拉框与折叠面板重构为原生 CSS Grid 动画，彻底消除文字虚化与残影。
